# OpenFun

[English](README.md) | **简体中文**

OpenFun 是一个 AI 沙盒游戏，让你创造、探索和改变自己的世界，看它如何回应你的行动，持续演化。

项目正在使用 TypeScript 重建。我们会先基于 PixiJS 构建 2D 版本，聚焦玩家与角色、环境的交互，以及世界对这些行为的记忆和持续反馈。在 2D 版本实现的效果不错的情况下，再推进 3D 版本的开发。

旧实现、依赖、测试和架构文档已移除。目前尚无可运行的应用或安装流程，旧实现仍可从 Git 历史中查阅。

新的架构设计文档与 README 将由项目作者手写，并随开发持续维护。

OpenFun 使用 [MIT 许可证](LICENSE)。
